# TOS 测试快速指南

## 运行 TOS 测试

```bash
pnpm run test:tos
```

## 测试内容

这个测试会验证以下功能：

1. **✅ 环境变量检查** - 确保 TOS 配置正确
2. **✅ 列出存储桶** - 验证账号权限
3. **✅ 上传文件** - 测试文件上传功能
4. **✅ 下载文件** - 验证文件下载和内容完整性
5. **✅ 获取元数据** - 测试文件信息获取
6. **✅ 列出文件** - 验证文件列表功能
7. **✅ 生成预签名URL** - 测试临时访问链接生成
8. **✅ 删除文件** - 验证文件删除功能
9. **✅ 实际文件上传** - 模拟真实场景的文件操作

## 所需环境变量

在 `.env` 文件中配置：

```env
VOLCENGINE_ACCESS_KEY_ID=你的访问密钥ID
VOLCENGINE_ACCESS_KEY_SECRET=你的访问密钥Secret
```

## 故障排除

### 环境变量缺失
```
❌ 缺少必要的环境变量:
  - VOLCENGINE_ACCESS_KEY_ID: ✗
  - VOLCENGINE_ACCESS_KEY_SECRET: ✗

请在 .env 文件中配置这些环境变量
```

**解决方案**：在项目根目录的 `.env` 文件中添加配置。

### 权限错误
```
❌ TOS 测试失败:
错误信息: AccessDenied
```

**解决方案**：
1. 检查密钥是否正确
2. 确保账号有访问 `comicgen` 存储桶的权限
3. 验证存储桶是否存在

### 网络错误
```
❌ TOS 测试失败:
错误信息: ECONNREFUSED
```

**解决方案**：
1. 检查网络连接
2. 确认防火墙没有阻止访问
3. 验证 TOS endpoint 地址是否正确

## 测试后清理

测试会自动清理所有创建的临时文件，无需手动操作。

## 用于实际开发

如果 TOS 测试通过，说明：
- ✅ TOS 配置正确
- ✅ 可以在项目中使用文件上传功能
- ✅ 可以生成预签名 URL 供前端使用

现在可以放心使用 `lib/tos.ts` 中的 TOS 客户端了！
